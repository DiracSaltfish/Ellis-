# 历史 PCF 数量交互浏览器

用于逐券检查 520600 历史 PCF 清单股数。支持代码/名称搜索、历史退出成分券、日期区间、滚轮缩放、拖动平移、全历史时间轴手柄、逐日差值、仅看变化日和当前筛选 CSV 导出。

## 启动和访问

在终端运行（Python 3.9+，不需要安装依赖）：

```sh
python3 '/Users/ellis/工具程序开发/港股通相关性分析/pcf_viewer/server.py'
```

也可双击同目录 `start.command`。程序默认监听 `0.0.0.0:8766`。

- 本机：http://127.0.0.1:8766
- 内网：http://192.168.1.23:8766 （2026-09-08 本机地址，IP 改变时需替换）

同一局域网的设备可访问；Mac 需要保持唤醒，防火墙需允许该端口。不要将端口映射到公网：此演示程序不带认证。它只暴露页面和所选 CSV 的清单数据，不提供目录浏览、文件修改或交易功能。

关闭前台终端或按 Ctrl+C 停止。若后台已经运行，重复启动会提示端口占用，可直接打开已有服务。可用 `lsof -nP -iTCP:8766 -sTCP:LISTEN` 查看进程。

自定义来源或端口：

```sh
python3 '/Users/ellis/工具程序开发/港股通相关性分析/pcf_viewer/server.py' --csv '/绝对路径/daily_components.csv' --port 8767
```

只允许本机访问时加 `--host 127.0.0.1`。

## 数据来源与刷新

默认读取本机 `/Users/ellis/工具程序开发/analysis_520600/daily_components.csv`，不在页面操作时读取网络挂载硬盘。首次验收快照：2024-12-30 至 2026-08-13，390 个 PCF 日期、16,392 条记录、69 个历史成分券。**这是现有整理数据的覆盖范围，不声称已更新到今天。**

点击“刷新数据”重新读取当前文件；文件未变则复用服务端解析结果。没有自动向网络硬盘同步或抓取新清单。CSV 如果包含多个基金会自动出现基金选择项。

必需字段：`date,fund_code,fund_name,component_code,component_name,quantity_shares`；可选字段：`cash_substitution_flag`。UTF-8（可带 BOM）；日期为 YYYY-MM-DD。服务端拒绝规范化代码后的重复基金/日期/证券记录、非法日期、负数和非有限数量。

## 图表口径

- 一行代表“基金 × PCF 清单日期 × 成分券”的每最小申购赎回单位股数，不是全基金实际持仓，也不直接等于指数权重。
- 港股代码统一为五位，去除源文件多余的前导零。此版本按港股代码域解释；不要混入跨市场同码证券。
- 横轴是该基金已有记录的 PCF 日期，等距排列；不是净值截止日期，也不填周末、休市或源文件整日缺失。快捷“近30/90/180日”均指最近相应数量的已有 PCF 日期。
- 某个已有 PCF 日期未列出该券时保留空值、曲线断开，不补零、不向前填充。数值 0 本身保留为真实 0；是否源文件遗漏需回查原始清单。
- 差值 = 当日股数 − 上一已有 PCF 日期股数。只有相邻两日均在列才计算，不能跨空值比较；前值 0 不计算百分比。
- “区间数量调整次数”只统计窗口内部相邻且均在列的数量变化。进入/退出单独标记；它不意味着指数正式调仓或基金真实买卖。
- “区间首末在列数量变化”比较窗口内最早和最晚的非空数量，下方注明两个实际日期。区间末日数量则严格对应窗口末日，未在列会显示“未列入”。
- 阶梯线强调离散清单变化；不表示两个 PCF 日期之间存在实际观测。纵轴默认自动缩放并标明，可勾选从零开始。变化柱用正负位置和数字共同区分增减，颜色只是辅助。
- 清单的最小申购赎回单位若发生变化，原始单篮股数的跨日可比性也会变化。当前明细源不含该单位份额字段，因此这里不自动做单位归一化。

## 操作

搜索代码或名称切券，保留当前窗口。主图滚轮缩放；按住拖动平移；底部导航两侧手柄调整窗口，拖动框内移动窗口；双击或“重置视图”看全部。键盘焦点在主图时，左右键平移、加减键缩放、Home 重置。悬停查看精确值；明细表可筛变化日，导出遵循当前日期和变化日筛选。
