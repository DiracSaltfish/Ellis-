# Excel 交付契约 v1.0

用户要求：每个任务结束有详细输出，列定义固定，便于主 Agent 验收。

本目录 `schema.json` 是逐列机器规范；Excel 的“字段字典”是同一规范的阅读版本。`ledger.json` 为可更新记录，`build_workbook.mjs` 从它生成 `港股通ETF_Agent任务交付.xlsx`。修改时先更新 JSON，再导出 Excel，禁止只改 Excel 导致下一次导出丢失。字段扩展必须升级 schema_version 并保持旧字段可读。不得删除不利结果和失败记录。

模板已初始化，不要运行 prepare_schema.py 重置台账。时间字符串统一带 +08:00；导出器按上海墙钟时间显示。每次更新运行以下命令（工作目录为本交接目录）：

```bash
'/Users/ellis/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3' validate_ledger.py
'/Users/ellis/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node' build_workbook.mjs
```

validate_ledger.py 非零退出时先修复，不能继续宣称导出通过。最终增加 --final 检查全部任务终态。结构校验只是最低门槛，条件必填、方法及来源真实性仍需按任务书检查。模板11张表已渲染验视，普通数值更新无需反复渲染；修改样式或新增布局时给 builder 增加 --render 并检查相应预览。node_modules 指向已配置的官方运行依赖，不复制或修改依赖目录。

## 表与粒度

- 使用说明：固定约定及公式计算的任务计数。
- 任务台账：一行一个阶段/基金/子步骤，任务ID唯一，依赖ID用分号。预置 G01—G06 与 210 个基金总任务；执行时追加 F-代码-S1…S5。终态必须写真实开始结束时间（未执行的范围排除可无开始时间但必须写判定时间）、结论、产物、来源与校验。未尝试的不能写 BLOCKED。
- 基金目录：一行一个候选基金，保留原名称和未认证状态；官方分类依据与沪深通道核验单列，运行状态与分类状态分开。
- 数据覆盖：一行一个 run×数据类型×证券×来源；预期/实际是同一日期范围下的有效日数，来源路径与 SHA256 可追溯。
- 证券事件：一行一个基金×证券×事件，链接原始公告，记录有效时间、影响日期、处理以及是否剔除整日。
- 工具映射：一行一个基金×对冲工具，经济依据、同指数组、实际合约、覆盖、纳入/排除与原因；建议工具未回测的状态为 proposed_only。
- 回测结果：一行一个 run×基金×周期×模型×场景；主场景为 BASE。保存 bp 指标、样本计数、窗口和配置指纹。Ridge beta 明细保存在独立文件，通过路径引用；不能把自动换腿模型写成固定组合。
- 敏感性：一行一个 run×基金×周期×模型×敏感性场景，同时保存主场景及当前样本组成。不可将不同样本结果变化解释成纯模型改善。
- 验收检查：一行一个 check×run，包括预期、实际、容差、结论、证据。只写“测试通过”不合格。
- 问题与重试：一行一个问题×尝试，记录时间、错误、修复/替代、影响范围、下一步。问题ID可多次出现，尝试序号联合唯一。
- 字段字典：上述每列的序号、机器键、类型、单位、必填条件和含义。

## 固定规则

1. ID 与证券代码存文本，保留前导零。比例存 0—1 实数，Excel 用百分比格式；波动、ES、残差单位 bp，1 bp=0.0001 收益率。方差下降可为负。日期为 Excel 日期，时间按 Asia/Shanghai，以真实发生时间填写。
2. 缺失数值为空并写缺失原因；0 是实际观测值。分钟明细、逐 fold beta、残差留在 Parquet/CSV，不塞进 Excel；用绝对路径及 hash 引用。
3. 任务状态固定：TODO、RUNNING、DONE、BLOCKED、EXCLUDED、INSUFFICIENT_HISTORY。DONE 表示该任务产物完成，不代表对冲有效或全市场认证。
4. 基金分类：UNVERIFIED、STOCK_CONNECT_HK_ONLY、QDII、MIXED_AH、OTHER、EVIDENCE_UNAVAILABLE。非港股通产品可完成分类任务但其基金总任务为 EXCLUDED，原因为研究范围。
5. 质量结果：PASS、FAIL、NOT_APPLICABLE。缺失依赖可用问题记录支撑 BLOCKED，不得伪填 PASS。
6. 必需独立校验：未来数据隔离、日期/合约边界、标量估值复算、样本计数一致、同指数互斥、指纹缓存失效、结果JSON与Excel一致。520600 精确复现按任务书阈值；其他输出容差要按量纲具体定义。
7. 终态任务须关联基金/run（全局任务例外）、产物、检查或明确阻塞/排除证据。所有被拒日期和缺价证券可追溯，负面结论照常保留。
8. 每个基金结束：写 ledger → 验证字段/类型/唯一键/引用/终态必填 → 生成临时 Excel → 校验计数与代表性数值 → 原子替换 → checkpoint。导出失败保留 JSON 并修复，不能说 Excel 已更新。
9. 初始模板所有研究任务均 TODO。已有 520600 报告只是复现参考，不提前记作 Luna 已完成。

## 最终验收入口

先看任务台账终态计数与基金目录的 210 条分母，再看 G02/G03 复现证据；选汽车/宽基或科技/其他主题各一只检查来源、事件、固定模型、敏感性与复算。对所有 BLOCKED、INSUFFICIENT_HISTORY、EVIDENCE_UNAVAILABLE 检查真实尝试与影响，不接受用空白隐藏缺口。
