# 单标的标准分析工作流 v1.0（初步价格研究）

2026-09-06 已由 520600 真实一分钟数据跑通。适用范围：同日下午、固定数量港股篮子的对冲相关性与残差风险研究。
此版本不要求 tick、成交量精确单位、盘口、券源或实际费用才能运行；这些只属于后续执行/套利收益阶段。

## 用户已确定的研究口径

- 港股通 PCF 成分统一按强制现金替代处理，原始旗标保留作追溯，不再将“未知/允许”作为本阶段阻塞。
- 一分钟价格足够。成交稀疏时使用当日最后可见价格；保存报价年龄和陈旧名义额权重。
- 正常使用相应通道的结算汇率。沪港通与深港通不能混用；买入港股支出对应卖出结算率，卖出收入对应买入结算率。
- 最终结算率只做人民币事后核算。日内恒定 FX 在收益率中抵消；不能声称已经对冲结算汇率预测误差。
- 停复牌和公司行动由 Agent 自行查询公开数据及发行人公告，已有确认不重复询问用户。

## 520600 已验证的固定流程

1. **读取任务卡和缓存索引。** 读取 `config/pilot.json`、本文件和 `data/inventory/remote_inventory.json`，不要重新扫描远盘。520600 采用 2026-03-03—08-03 的 100 个共同文件日。
2. **明确基金与目标。** 以当天 PCF 数量篮子为目标；ETF 场内价格只作旁证。候选基金名称不是法律分类，扩展其他基金前检查实际指数、通道及混合 A/H 情况。
3. **远端定向抽取。** `extract_pilot_remote.py` 在 machome 读取日包和目标 PCF，只输出该基金成分与 02800/02828/03032/03033/02845 的一分钟 OHLC；保留源路径、大小和 mtime，gzip 传回并校验。支持斜杠日期和带秒的连字符日期。
4. **复用汇率和期货。** 优先从 `/Users/ellis/newnavnav/港股通汇率研究` 读取已抓取沪港通结算率及 HSI/HHI；缺 HTI 时运行 `collect_hti.py`，依 HHI 实际月份映射逐合约抓取，缓存每个请求结果，断点可重跑。不得改动 newnavnav 采集服务或原文件。
5. **核查证券事件。** 成分代码并集交给 `fetch_corporate_actions.py` 做公开事件筛查；缺价、拆股、代码复用和临时柜台必须用 HKEX/发行人公告核验。58/60 代码抓取成功不能标全事件完备。代码缺失不等于停牌。
6. **事件处理。** 已确认停牌才允许以前次可见价格冻结估值，保留全部数量和冻结权重，并做去掉停牌日期的敏感性检查。复杂分派权益无法定价时剔除整个基金日，记录理由，不删股票重新归一化。普通拆股/分红使用当天 PCF 与未复权当日价格，不跨日收益，不再重复乘拆股因子。临时代码按每日实际 PCF 读取。
7. **形成分钟估值。** `basket_HKD=sum(quantity_i*price_i)`；申购方向暂估每份价值 `(basket_HKD*settlement_sell+PCF_estimated_cash)/creation_unit`。该值是本研究的简化估值，不是认证 NAV/IOPV。不得用 PCF 固定替代金额推算市场价格。
8. **时间与报价年龄。** 输入先按分钟开始标签解释，价格在下一分钟可用。首轮使用 13:00—14:59 标签，对应 13:01—15:00 可用时刻；不取含15点以后信息的15:00柱。同一日下午 LAST 延续允许，但标记五分钟以上陈旧敞口；不给缺失的未来报价后向填充。
9. **生成标签。** 5/15/30/60 分钟分别计算固定数量篮子和各工具的收益。标签不能跨日、午休或实际合约。所有候选在同一组有效端点上比较。期货收益是价格差除起点价格，真实期货 PnL 另用张数×乘数×价格差，不能给名义本金附加 FX 收益。
10. **设置基准。** 不对冲、8 个单工具，以及预先定义的 HHI＋HTI 双腿对照；保留 HTI 单腿。候选模型最多两腿，同指数产品互斥，避免把 HTI 与恒科 ETF 的重复敞口误当独立因子。
11. **滚动样本外。** 每个测试日前60个可用日：前50日拟合、后10日选候选及 ridge alpha（0/0.01/0.1），再以全部60日重拟合；下一日才是外测。beta每腿0—2，总和不超过2.5。没有截距收益，不对冲也是可选项。评分为验证 RMSE＋0.2×较大方向 ES95；纯风险分数不冒充低成本最优。
12. **输出证据。** 标准差、方差下降、正负方向 ES95、绝对残差95分位、平均残差、日度beta、候选频率、样本量和拒绝比例；全部用bp/百分比清晰区分。重叠标签不是独立交易，置信区间按完整交易日bootstrap。
13. **必须做敏感性检查。** 端点陈旧权重≤2%/5%的评价子样本；≤2%重拟合；对冲时间偏移±1分钟且冻结原日度权重；剔除冻结停牌日后重拟合。各场景样本组成不同，分别报告，不能挑最优场景作为主结论。
14. **验收与解释。** 数学测试、未来数据扰动测试和真实分钟标量复算通过后生成结果及Notebook。报告简单基准是否胜过复杂选模、单腿到双腿的边际提升以及尾部仍有多大。费用未知只标 `PASS_RISK_ONLY_WITH_CAVEATS`，不能推算净套利利润。

现有实现是已验证的520600试跑，不是已认证的全基金自动平台。推广时先做一个标的的配置化适配，再锁定共享代码；不得靠批量字符串替换覆盖本次基准目录。

```text

读取指定 manifest、v1.0 工作流和用户已确定的口径，不重复要求tick/成交量/PCF旗标确认。
先复用源池，只抓取该基金新增成分；每个标的使用独立输出目录，保留520600基准。
自行核查新增停复牌、公司行动、临时代码和重用代码；失败保留明确状态。
沿用训练/验证/外测切分和同指数互斥规则；不得查看外测后再调参重算并冒充首次外测。
运行固定质量检查、收益标签检查、数学测试及敏感性检查。
交付固定产物和简短结论：最有希望的基准、备选、边际改善、残余尾部、数据局限。

```

## 本次得到的可复用结论

主题相似不保证有效；同指数工具不能重复当独立因子；复杂选择未必优于简单双期货基准；一分钟陈旧价格值得检查，但无需先索取tick才能完成初筛。
