# 批量验收字段说明

每个基金代码至少应有以下验收项。`PASS` 只表示已有来源支持该项；`PENDING` 表示需要基金管理人、托管人或结算参与人确认；`PASS_WITH_WARNING` 表示第三方镜像、字段定义或时效存在风险。

## 项目特别验收标准

对“是否 RTGS”这一项，只要基金特定招募书或适用的中国结算/交易所规则明确出现“日间 RTGS 交收”（或“日间实行 RTGS 交收”等同义表述），就判定该项 `PASS`。资金足额、是否选择 RTGS、日终未完成时的回退方式作为备注记录，不影响该项 PASS。

## 字段

| 字段 | 判定规则 |
|---|---|
| latest_prospectus_date | 公告标题命中“更新招募说明书”，按公告日期取最新；不能用产品资料概要日期替代 |
| fund_class | 根据招募书/深交所规则判定：跨境ETF、跨市场股票ETF、单市场股票ETF等 |
| pcf_asof | 当前交易日 PCF 的实际 T 日，不只记录抓取日期 |
| pcf_source_grade | 基金公司/深交所为 A；中国结算或官方镜像为 B；第三方数据平台为 C |
| cash_substitution_flag | 至少记录申购/赎回标志、现金替代保证金率、159900 是否存在 |
| creation_buy_deadline | 申购现金替代的底层买入时点：T日、T+2、或其他；必须保留原文 |
| redemption_sell_deadline | 赎回现金替代的底层卖出时点及未成交的估值规则 |
| subscription_cash_substitution_mode | 申购现金替代的结算方式，如日间 RTGS、逐笔全额交收；招募书未直接说明时不推断 |
| subscription_cash_substitution_settlement_time | 申购现金替代在登记结算层面的交收时点；与基金管理人实际补券时点分开 |
| subscription_fund_units_settlement_time | 申购基金份额完成清算交收的时点；不等同于可卖出时点 |
| subscription_fund_units_available_time | 申购份额可卖出/可赎回的时点，区分日间 RTGS 成功与日终交收成功两种路径 |
| rtgs_subscription | 只要命中“日间 RTGS 交收”即可 PASS；条件和回退批次另列备注 |
| redemption_fund_units_settlement_time | 赎回基金份额交收时点，通常与申购份额交收时点不同 |
| redemption_cash_substitution_mode | 赎回现金替代的结算方式，如代收代付；招募书未直接说明时不推断 |
| redemption_cash_substitution_arrival_time | 赎回现金替代款划往基金份额持有人账户的时间；优先记录“自有效赎回申请之日起 T+N 个开放日/工作日内”，不得用底层卖券日替代 |
| constituent_suspension_handling | 根据招募书记录成分股停牌专门条款；同时标出长期停牌/流动性不足导致价格不公允时的估值调整、复牌后实际成本/合理价格办理，以及停牌导致无交易时的收盘价兜底。没有专门条款不得自行写成“停牌必然必须现金替代” |
| subscription_consideration_calculation | 申购对价/现金替代金额公式：可现金替代通常为替代证券数量×申购清单规定价格×估值汇率×（1+溢价/保证金率）；同时记录 T 日终实际买入成本、未买入部分计值以及退补差额 |
| redemption_consideration_calculation | 赎回对价/现金替代金额：实际卖出所得扣除费用后按汇率折算；未卖出部分按对应未卖出价格规则计值并加入；必须现金替代的固定替代金额另列在同一字段或证据中 |
| subscription_replacement_purchase_rule | 申购替代证券由基金管理人代投资者买入的具体动作、最迟时点、是否可不买入部分/全部，以及是否涉及同日申赎轧差后的未下单部分 |
| redemption_replacement_sale_rule | 赎回替代证券由基金管理人代投资者卖出的具体动作、最迟时点、是否可不卖出部分/全部，以及是否涉及同日申赎轧差后的未下单部分 |
| subscription_unpurchased_price_rule | 申购时未补券部分的计价价格；通常是 T 日或 T+1 日收盘价，并记录当日无交易取最近交易日收盘价、无收盘价取最后成交价等兜底 |
| redemption_unsold_price_rule | 赎回时未卖出部分的计价价格；通常是 T 日或 T+1 日收盘价，并记录当日无交易取最近交易日收盘价、无收盘价取最后成交价等兜底 |
| redemption_settlement | 赎回份额和现金替代分别采用何种交收方式 |
| cash_difference_announcement_time | T 日现金差额在何时的申购赎回清单公告；公告日和资金交收日分开记录 |
| cash_difference_clearing_time | 现金差额由基金管理人/登记机构办理清算的时点；仅能从公告时点侧面推定时要保留限制 |
| cash_difference_settlement_time | 现金差额实际交收时点，通常晚于公告或清算时点 |
| subscription_cash_substitution_refund_time | 申购现金替代退补款的明细发送、退款/补款交收时限；不改写为底层补券时间 |
| cash_difference | 现金差额的清算日、交收日、公告日偏移 |
| cash_substitution_adjustment | 申购退补款、赎回替代款的明细发送和交收日 |
| same_day_netting | 必须区分中国结算清算层面和基金管理人底层证券交易层面；没有基金特定明示就标 PENDING |
| same_day_netting_basis | 同日申赎轧差的基金特定原文摘录；仅在 `same_day_netting_manager=PASS` 时填入，不用中国结算层面的 RTGS/代收代付规则替代 |
| nav_calculation_time | 基金收盘净值/基金份额净值的计算时点，如 T 日收市后、每个估值日交易结束后；未明确则待人工复核 |
| nav_announcement_time | 基金份额净值对外公告时点，如 T+1 日内；不得用 IOPV 发布时点替代 |
| nav_price_basis | 收盘净值中境外上市证券的价格口径，如估值日收盘价、最近交易日收盘价或公允价值调整 |
| nav_precision | 基金份额净值精度及四舍五入规则；与 IOPV 精度单独记录 |
| nav_fx_source | 正常港币/港元→人民币路径的汇率来源摘录；只从“基金资产估值/外汇汇率”条款提取，不并入小币种备用路径 |
| nav_fx_normal_method | 面向本批港股通标的的正常港币估值汇率结论；优先记录估值日/当日中国人民银行或授权机构人民币对港币汇率中间价，不展开未公布小币种备用路径 |
| nav_fx_reference_time | 正常港股通港币估值汇率的取价日/时点，如估值日、当日、最新公布；原文未写不得从 T 日交易动作推断 |
| nav_fx_currency_scope | 本批统一记录为港币/港元→人民币（港股通），不展开未公布的小币种 |
| nav_fx_fallback | 本批不纳入小币种/备用路径；完整原文仅在自动摘录证据中保留 |
| creation_replacement_fx_rule | 申购补券实际买入成本、未买入部分收盘价折算及退补款计算规则；费用计入方式可在 `cash_substitution_fee_rule` 查看 |
| creation_replacement_fx_source | 申购补券/实际买入结算汇率来源；不得用 `nav_fx_source` 或 IOPV 汇率来源填充 |
| creation_replacement_fx_reference_time | 申购补券实际结算汇率的取价时点；仅在补券条款明确出现时点才填写 |
| creation_replacement_fx_currency | 申购补券实际折算涉及的币种及方向 |
| redemption_replacement_fx_rule | 赎回代卖实际卖出金额、未卖出部分收盘价折算及赎回替代金额计算规则 |
| redemption_replacement_fx_source | 赎回代卖/实际卖出结算汇率来源；不得与基金资产净值估值汇率混同 |
| redemption_replacement_fx_reference_time | 赎回代卖实际结算汇率的取价时点 |
| redemption_replacement_fx_currency | 赎回代卖实际折算涉及的币种及方向 |
| cash_substitution_fee_rule | 申购实际买入成本是否包含买入价格/交易费用、赎回实际卖出金额是否扣除费用 |
| iopv_formula | 基金份额参考净值公式；IOPV 是盘中参考值，不是收盘基金份额净值 |
| iopv_price_basis | IOPV 使用的证券价格口径，如实时成交数据、最新成交价或收盘价 |
| iopv_fx_source | IOPV 盘中汇率/汇率公允价来源；与 `nav_fx_source` 分开 |
| iopv_fx_reference_time | IOPV 汇率取价时点，如实时汇率数据或原文规定的时点 |
| iopv_publisher | IOPV 的计算方和发布交易所 |
| iopv_frequency_precision | IOPV 发布频率/交易时段和小数位精度 |
| operational_contact | 待确认问题、对象、确认日期、确认材料或邮件编号 |

## 批量验收最低证据

每个标的至少保存：

1. 发行运作公告接口结果；
2. 最新更新招募说明书 PDF 或原始公告链接；
3. 当前 PCF 原文件或原始网页；
4. 规则来源（深交所/中国结算）；
5. 对“补券、RTGS、赎回、轧差”四项分别留存原文附近段落；
6. 与第三方数据不一致时，在 `open_question` 中写明冲突，不要静默覆盖。
