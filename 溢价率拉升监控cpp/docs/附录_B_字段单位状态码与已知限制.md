# 附录 B：字段单位、状态码与已知限制

## 1. 核心固定点单位

核心层不使用二进制浮点保存行情值。只有 UI 和兼容协议边界把整数格式化为小数。

| 类别 | 核心字段示例 | 原始整数比例 | 展示换算 |
|---|---|---:|---:|
| 价格 | `last_price_e6`、`bid_price_e6[]`、`ask_price_e6[]` | `1e6` | 整数 ÷ 1,000,000 |
| IOPV | `iopv_e6` | `1e6` | 整数 ÷ 1,000,000 |
| 数量 | `volume_e2`、盘口数量 | `1e2` | 整数 ÷ 100 |
| 金额 | `turnover_e5` | `1e5` | 整数 ÷ 100,000 |
| 溢价率 | `sellable_premium_ppm` | `1e6` | ppm ÷ 10,000 后显示为百分数 |

固定点溢价率采用整数运算：`(bid1_e6 - iopv_e6) × 1,000,000 / iopv_e6`。所有比例映射在盘中验收前都属于“待验证”，不得仅凭字段名假定单位正确。

## 2. 行情与质量状态

| 状态/质量位 | 含义 | 对计算和发布的影响 |
|---|---|---|
| `WAIT_FULL` | 新连接、重连或分片丢帧后尚未收到该标的 full | 禁止发布和信号计算 |
| `READY` | 已有本会话 full，且最近 delta 合并有效 | 正常发布；是否计算再由时段决定 |
| `STALE` | 非行情时间或源数据超过时效 | 继续提供缓存并显式标旧 |
| `STATIC_IOPV` | 至少 5 帧且 IOPV 连续 120 秒不变 | 特殊颜色/文字，仍允许计算和提醒 |
| `INVALID_IOPV` | 缺失、非整数、≤0 或比例异常 | 禁止计算 |
| `INVALID_BOOK` | 档位数组错误、买一≤0、价格顺序/结构无效 | 禁止计算 |
| `price_tick_0_001_invalid` | 非零场内价格 e6 不是 1,000 整数倍 | 保留原始整数和证据，禁止计算；不自动四舍五入 |
| `TYPE_ERROR` | 数字键对应值类型不符合映射 | 当前事件隔离并记录原始证据 |
| `UNKNOWN_TAG` | 收到未纳入映射的数字键 | 保留原始值、计数和告警，不猜测语义 |
| `SEQ_GAP` | `adapter_seq` 不连续或有界队列溢出 | 清空对应分片，所有标的重新等待 full |
| `DISK_DISABLED` | 写队列满或可用磁盘低于阈值 | 停止历史写入并严重告警；计算和主动推送继续 |

## 3. 进程与时段状态

| 状态 | 含义 |
|---|---|
| `STOPPED` | 进程未运行 |
| `STARTING` | 子进程已启动，等待监听/登录 |
| `RUNNING` | 进程存活；TGW 是否有效须另看会话和字段质量 |
| `RESTARTING` | 监管器正在自动拉起 |
| `FAULT` | 5 分钟内已重启 3 次，停止自动恢复并等待人工处理 |
| `AUCTION_RECORD_ONLY` | 09:15–09:30，只接收和记录 |
| `AM_WARMUP` | 09:30–09:31，清空窗口后预热 |
| `AM_SIGNAL` | 09:31–11:30，允许规则触发 |
| `MIDDAY_RECORD_ONLY` | 11:30–13:00，只接收和记录 |
| `PM_WARMUP` | 13:00–13:01，清空窗口后预热 |
| `PM_SIGNAL` | 13:01–14:57，允许规则触发 |
| `CLOSE_RECORD_ONLY` | 14:57–15:00，只接收和记录 |
| `UPSTREAM_OFF` | 15:00 后退订 TGW；8421、19195 继续监听 |

## 4. QMT 指令结果

| 状态 | 客户端处理 |
|---|---|
| 已明确成功/失败 | 解除同标的同方向按钮锁，刷新当日委托 |
| 结果未知/连接断开 | 锁 10 秒并主动查询当日委托；不自动重发 |
| 10 秒后仍未知 | 允许用户再次双击；UI 持续显示风险提示 |
| 部分成交 | 委托继续保留，允许按 QMT 后端既有协议撤单 |

## 5. 明确保留的风险选择

- A/B 与 19195 位于可信内网，使用明文通信，不提供 TLS 或认证。
- 静态 IOPV 仍参与信号计算。
- 回放模式保留可操作的真实交易按钮，并以持续红色 `REPLAY` 水印警示。
- A 断线或报价过旧时，B 允许使用最后一个非零买一缓存价快速卖出；持续红色警告不构成技术拦截。
- QMT 后端不增加幂等键；超时只锁定 10 秒，系统不会自动重发。
- 第一个盘中 TGW 验收日正常发出声音和弹窗提醒。
- Windows 首阶段只提供共用源码、平台隔离和 MSVC CMake Preset，未在 Windows 主机生成或验证安装包。

## 6. 盘中验收前不得宣称通过的项目

- 1–21 映射和 202 短时批量/追加/单标的移除已有盘中证据；未覆盖长时间和重连。
- 重连后 full 恢复与自动重订阅在真实会话中的表现。
- 500/1000 标的订阅上限、SDK 10,000 事件队列水位和持续吞吐。
- IOPV 的来源、更新节奏与业务正确性；Sina L1 不能充当其独立真值。
- 价格、五档、数量、金额和原始行情时间与 Sina L1 对照后的统计一致性。

以上项目只有在按 `docs/10_盘中TGW正式验收手册.md` 留存原始帧并完成盘后人工审阅后，才能从“待验证”改为“通过”或“失败”。
