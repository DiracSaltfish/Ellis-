## 5. 对实现的直接结论

1. canonical key 必须由 tag 16 的键 2 生成 `02800.HK`；键 1 是 market，不能被当成代码。
2. adapter 的 `.HK` 必须使用 `market=102, public_flag=12`，且 code 保持五位字符串。
3. 不能复用沪深普通快照的数字键映射；需要独立 `mapHktSnapshot`。
4. HKT 必须支持 full 后多次 delta、运行中重复 full 和重连后重新等待 full。
5. 当前样本没有 IOPV，港股热维护必须绕过溢价率/拉升信号计算。
6. 当前样本只有一档非零，但载体是五个槽位；19195 仍按五档输出，零档保留为零值。
7. 最新价应取键 11；键 8 nominal 单独保留，不可在无明确规则时互相冒充。
8. 该验证不支持“沪港通回退”的必要性；产品约束明确只保留深股通。
