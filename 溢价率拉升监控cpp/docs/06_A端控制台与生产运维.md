# 06｜A 端控制台与生产运维

## 界面能力

A-console 显示 core/adapter 进程状态、监管器状态、工程目录、时段、就绪数、SDK/分片/落盘队列、核心延迟、可用磁盘和隔离数。可启停/重启、清屏、校验配置、通过 A 请求最近 TGW 原始帧、盘外人工开行情和选 raw 文件回放。

主工作区分为四个页签：

- **实时拉升告警**：直接消费 A-core 的 8421 `signal`，显示触发时间、标的、名称、模型、溢价率、四个滚动窗口指标、首次/重复、来源和触发依据。连接时最近 30 分钟补发只显示、不响铃；新的生产实时信号默认连续两次系统提示音并发托盘通知。响铃和系统通知开关保存于 `config/console-settings.ini`。
- **历史信号审计**：后台读取 `data/signals-YYYYMMDD.jsonl`，支持日期、证券代码和模型筛选；双击可查看完整原始 JSON、审计文件名和行号，也可导出当前筛选结果为 UTF-8 CSV。为避免 UI 卡顿，表格最多展示最新 50,000 条，原始文件不截断。
- **观察标的管理**：维护沪深观察清单。
- **运行日志**：显示 core、adapter、回放、原始帧和信号到达日志。

实时和历史信号均可双击打开详情。新格式审计记录保存触发时刻的最新价、买一、IOPV、`orig_time`、session、映射版本和质量位；旧格式缺少的字段明确显示“旧记录未保存”。详情中的“当前最新缓存”单独标识，禁止拿当前行情冒充历史触发行情。

观察列表区支持输入 6 位代码、选择上海/深圳后添加；表格多选后可删除。保存使用 `QSaveFile` 原子替换，运行中通过 loopback 8421 立即更新 core/adapter，添加等待新 full，删除会清窗口并精确退订。初始清单为 202 个标的，运行清单允许 1–1000 个唯一沪深代码；名称表缺失的新代码以 6 位代码临时显示，不阻止启动。

启动时 core 必须通过 JSON、唯一合法沪深清单和容量校验，否则直接失败。关窗只进托盘；托盘「明确退出」才终止子进程。

## machome 部署

原生 C++ TGW 分支目前只在本机改造和验证，**尚未部署或测试于 machome**。运行中的旧 Python TGW 版本保持不变。未来上线前，machome 需要先具备 `tgw_cpp` 源目录或已安装的 CMake package，以及 OpenSSL、zstd、simdjson、Qt 6；不再需要为 TGW 创建项目私有 Python wheel。

```bash
cd '/Users/ellis/工具程序开发/溢价率拉升监控cpp'
cmake --preset macos-arm64-release
cmake --build --preset macos-arm64-release -j4
```

配置 `config/app.json`/`config/tgw_account.ini`，确认权限仅当前用户可读。然后：

```bash
build/native-macos-arm64-release/etf-premium-console.app/Contents/MacOS/etf-premium-console \
  --root '/Users/ellis/工具程序开发/溢价率拉升监控cpp'
```

需要在不接管现有生产进程的情况下旁路查看告警/审计时追加 `--no-autostart`。该模式不启动、停止或监管 core/adapter，启动/停止/重启/盘外行情/回放按钮会禁用，但仍会主动连接并在断线后重连本机 `8421`；观察清单、原始帧、配置校验与告警审计仍可使用。

## 盘前检查

1. 系统时区 Asia/Shanghai，时钟同步，日期是预期交易日。
2. 剩余磁盘 >20 GiB，特别是容量采集日。
3. 8421/19195 无端口冲突，防火墙只允许可信内网。
4. `app.json mode=live`，`tgw_account.ini` 与 CA 文件权限正确，QMT 地址正确；容量日才开 dynamic capture。
5. 09:15 看 `etf-premium-tgw` 的 `tgw_logged_in/subscribe_accepted`；09:30 看窗口清空；09:31 看 signals_enabled。

## 告警处理

| 告警 | 立即动作 |
| --- | --- |
| `FAULT` | 不反复点启动；先看最后三次退出错误 |
| adapter gap/queue overflow | 停扩容，保留 raw/core/adapter 时间段 |
| worker drop | 严重；分片已等 full，继续观察 ready 恢复 |
| quarantined 持续增长 | 查 quality 键/类型，不盲目放开映射 |
| historical writes stopped | 实时继续；立即清磁盘/转移分区并记录证据缺口 |
| B 断线 | 检查 8421/网络；A 不停计算 |
| A-console 无声音 | 检查“实时信号响铃”、macOS 系统提示音音量；确认记录来源不是补发/回放 |

## 日志

`logs/a-core-YYYYMMDD.jsonl`与 adapter 每日轮转保留 30 日。不在任何日志记录 TGW/QMT 密码。排障最小集：app 脱敏副本、A/adapter/B 日志、同时段 raw/normalized、quality report、Sina L1 对照报告。
