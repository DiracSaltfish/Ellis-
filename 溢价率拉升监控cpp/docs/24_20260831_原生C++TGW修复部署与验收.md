## 2. 故障原因与修复

旧部署在周五收盘至周一开盘期间一直保留 Python TGW 进程。周一登录失败后，A-core 没有在同一 adapter session 的失败状态上废弃缓存，因此 19195 仍可能把上个交易日快照作为当前行情发布。

本次修复包含：

- A-core 显式维护 `upstream_healthy` 与 `upstream_status`。
- 适配器断开、session 改变、序号缺口、`tgw_session_closed`、`tgw_connection_failed` 或 `native_worker_failed` 时统一废弃所有行情缓存和计算分片状态。
- 上游未恢复健康时拒绝行情事件，8421 不补发旧 summary/detail，19195 不发布旧 book。
- 原生适配器关闭 live session 后更换 session ID、清空事件队列；仿真停用后也必须创建新 session 并重新取得 full。
- 新增端到端 session boundary 测试，覆盖“同 session 失败状态清缓存”和“仿真停启后重新 full”。
- macOS 发布包内置与构建版本一致的 `libsimdjson.33.dylib`，避免 machome Homebrew simdjson ABI 不同造成原生进程无法启动。
