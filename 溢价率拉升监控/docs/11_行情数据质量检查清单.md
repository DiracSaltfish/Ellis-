# 11｜行情数据质量检查清单

## 原始包与身份

- [ ] JSON/ZSTD envelope 可解，tag/status/is_delta/data 类型正确。
- [ ] 统计 full/delta 数、比例、key set 和每 key JSON 类型；未知 key 保留证据。
- [ ] adapter_seq 在 A 入站无缺口；注意 raw 文件不存 status/control，文件内 market seq 不连续本身不等于丢帧。
- [ ] full/delta 的 market+symbol+tag 稳定，不存在多标的状态串写。
- [ ] 重连之后旧状态清空，每标的取新 full 后才 ready。
- [ ] 退订 60s 宽限、重订阅和底层回应一致。

## 类型和缩放

- [ ] price/high-low/limit 都是 int64，除 `1e6` 后与 Sina L1 同数量级；IOPV 单独检查。
- [ ] 所有非零场内价格 e6 均为 1,000 整数倍（0.001 价位）；任何 `price_tick_0_001_invalid` 保留 raw，不允许 UI 四舍五入掩盖。
- [ ] volume/bidVol/askVol 除 `1e2` 后 19195 为股/份；与 Sina L1 数量比分布排除 1/100、100 等倍率。
- [ ] amount 除 `1e5`，与量价数量级相容。
- [ ] 不存在 float/string 冒充 int、NaN/Inf、负数、数组长度/项错位。
- [ ] IOPV >0，price/IOPV 比值分布合理；疑似倍率异常单列。

## 档位、累计值和时间

- [ ] 十档长度=10；买价递减，卖价递增；交叉、零档、买卖错位单列。
- [ ] last 在已提供 high/low 和涨跌停内；pre-close/open/close 语义正确。
- [ ] 同 session+symbol 的成交量/额/笔数盘中单调；日切/session 切换不误报回退。
- [ ] `orig_time` 是 17 位交易所时间或已证 epoch ms，无异常倒退；重复/更新间隔分布可解释。
- [ ] 集合竞价/午休/收盘 phase 与时间一致。
- [ ] IOPV 零/缺失/静态持续时间统计；静态仍提醒但界面强标。

## 延迟与容量

- [ ] TGW→adapter 需外部源时间可比时才计；adapter receive→A publish 统计 p50/p95/p99/max。
- [ ] A publish→B receive 由 B 同步时钟日志统计，不用未同步主机做精确延迟。
- [ ] SDK queue high-water、adapter drop、四分片 depth/peak/drop、落盘 depth/peak/stop 全部有数。
- [ ] 202/500/1000 各至少 15min；拒绝/持续积压/严重异常立即停扩容。

## Sina L1 独立对照

- [ ] 按 `qt` 附近样本比 last、五档价、五档量，输出匹配率/价差/档差/量比。
- [ ] 允许并记录源更新时点不同的正常采样差，不将所有不同自动判错。
- [ ] Sina L1 不提供本项目可用的 IOPV 真值；报告明确写「IOPV 未被独立源验证」。

## 人工分类

1. 确定错误：类型/倍率/身份/档位证据闭环。
2. 疑似异常：统计极端但源时间或参考不足。
3. 正常采样差：近时间不同快照、限频覆盖中间态等。
4. 尚无法证明：如 IOPV 无独立源。
