# 04｜19195 兼容 L1 协议

`0.0.0.0:19195` 是明文 TCP NDJSON v1，与原 `L1内+Backend9.9 V1(不含L2)` 合同保持兼容；旧 CPPETF UI 只需改主机地址。不混入 IOPV/映射/新字段。

## 握手、请求、容量

首帧 `hello` 含 `v=1,t=hello,service=qmt_l1,port,publish_mode=event_driven,coalesce_ms=0,ping/idle,max_clients,defaults`。客户建议 15s ping，45s 无有效 v1 入站断开。

```json
{"v":1,"t":"subscribe","id":"x","symbols":["159518.SZ"],"interval_ms":0}
{"v":1,"t":"unsubscribe","id":"x","symbols":["159518.SZ"]}
{"v":1,"t":"status","id":"x"}
{"v":1,"t":"ping","id":"x"}
```

新客户可在不改消息结构的前提下请求 `02800.HK`。港股代码必须是精确五位数字 + `.HK`；`2800.HK`、六位 `.HK` 和 `.SH/.SZ` 长度错误会在原有 `ack.rejected` 内以 `invalid_symbol` 拒绝。旧 CPPUI 只请求 `.SH/.SZ`，无需改代码或解析器。

`t` 兼容 `op/type`；subscribe 增量添加，interval 限 0–60000ms。单客户 256 symbol、全局 1000、256 客户。单行上限 65,536 bytes；初始多标的快照按单标的兼容 l1 帧拆分。

`interval_ms=0` 每个新版本立即发送；大于 0 时每标的独立保留最新 pending 快照，到期由专用定时器补发，不会因期间再无新 Tick 而永久漏掉最后一版。单客户端待写缓冲超过 1 MiB 即断开该慢客户端，不阻塞其他会话。

错误码：`invalid_json/bad_request/unsupported_version/unknown_operation/client_symbol_limit/server_full/line_too_large`；单标的容量拒绝在 subscribe `ack.rejected` 返回。

## l1 推送

```json
{"v":1,"t":"l1","seq":1,"ts":1784941200200,"books":[{"s":"159518.SZ","qt":1784941200123,"rt":1784941200130,"lp":1.234,"o":1.2,"h":1.25,"l":1.19,"pc":1.21,"vol":12345600,"amt":15234560.0,"st":0,"ap":[1.235,1.236,1.237,1.238,1.239],"av":[10000,20000,30000,40000,50000],"bp":[1.233,1.232,1.231,1.23,1.229],"bv":[11000,21000,31000,41000,51000]}]}
```

只输出五档；价格为人类小数，vol/av/bv 是股/份，amt 是人类金额。`qt` 是 TGW orig_time 转 Unix ms，`rt` 是 adapter 接收 Unix ms。新订阅有缓存即立即快照，否则 l1 带 `missing`。

当前 A 观察清单（初始 202）与独立 L1 热维护列表共同形成 pinned 并集。两列表重叠的证券上游只订阅一流，但观察资格优先。`hello.defaults` 仍只含观察清单，因此旧客户语义不变；`status` 可选增加 `hot/pinned`，不影响旧解析器。外部动态订阅按所有 TCP 会话并集引用；最后引用消失后 60s 才向 TGW 退订。

`02800.HK` 内部固定映射为 `code=02800, market=kSZSE(102), flag=kHKTSnapshot(12)`，不做沪港通回退。其 `books` 仍是原 v1 五档结构，`o=0`（HKT 快照没有可靠开盘字段），不添加 IOPV 或任何新业务键。沪深维持 09:15–15:00，深港通维持 09:30–16:00，中午不退订。19195 全天监听，非行情时间仍接订阅/status，但不伪造新快照。

## A 能否主推 UI

**协议能力满足。** v1 原本就是 event-driven 主推；A 每形成新快照即投递 19195，仿真已通过 hello/ack/missing/l1。但 TGW 真实字段和延迟未验收，故生产结论仍是「待盘中验证」。
