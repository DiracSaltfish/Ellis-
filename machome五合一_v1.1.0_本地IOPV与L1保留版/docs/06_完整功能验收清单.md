# 06 完整功能验收清单

本清单是上线 gate，不是建议列表。每项必须记录：执行人、时间、构建 ID、配置 hash、输入、预期、实际、证据路径、结论。`N/A` 需要业务负责人签字说明。

## 如何使用本清单

这里的复选框刻意保持未勾选：**本机 mock 通过不等于 machome 生产放行**。实施时给每项标记以下证据等级，并且只有 P 级通过才能勾选涉及真实业务的条目：

- `L`：本地单元/UI/mock 自动化；
- `S`：machome shadow，只读且与旧页面并行对照；
- `C`：单模块受控 mutation/切换；
- `P`：完整真实时段、长稳和回滚均通过。

当前 `L` 级证据为默认 CTest 15/15、native CTest 16/16，外加 newnavnav 覆盖层 77/77 隔离回归；覆盖协议帧、四页面、8421 summary/detail 与 19195、Webull runner、6787 嵌套结构、生产风格 QMT 整数快照 ID/浮点校验和 QMT1/QMT2、原生 IBKR 严格配置/QuoteBook/动态租约/慢客户隔离、11 条成功控制、Upload 单 unit 生命周期、stale revision、幂等冲突、owner 交接合同、构建清单、发布 dry-run、关键审计崩溃恢复/慢盘隔离与 SIGTERM 退出。本机 TWS 7496 另有不上传的真实行情 smoke 证据。对应详情见 [08 本地实现与测试报告](08_本地实现与测试报告.md)。A-01/E/F/G/H 的远端事实有只读快照，但因版本漂移、盘外状态和未做 owner 交接，尚不能直接记为 P。
