# 四合一运行中心：界面改版与本地验收

已完成运行总览和四个服务概况页的重设计，新增统一的中文显示层。界面改版首先通过本地验收，随后经用户授权以仅更新界面的补丁部署至 machome，详见 [部署验收](部署验收.md)。未更新 DMIT，未停止后台业务服务或调用交易接口。

## 改版内容

| 页面 | 默认突出显示 |
|---|---|
| 运行总览 | 四个服务卡片、业务状态、关键指标、最近更新时间与服务入口 |
| 网站与数据上传 | 运行任务、已就绪任务、有接收确认记录的任务、未通过检查和中文原因 |
| 行情与拉涨监控 | 行情覆盖、额外基础行情、行情源健康、客户端连接、当前信号时段 |
| Webull 行情转发 | 登录、采集、数据就绪、客户端连接；明确区分无行情和行情过期 |
| ETF 申赎监控 | 份额监控、标的数量、申赎清单就绪、Wind 状态及 QMT 数据连接 |

原始状态树收进默认折叠的“诊断详情”。字段名优先显示中文，悬停可查看原始字段及值；协议字段和控制指令保持原值，不使用中文字符串参与业务判断。

常见状态、任务名称、操作名称和页签已中文化，例如 capabilities、managed、native、Debug、NAV、Client ID 和 fail-closed 对应的日常显示。未知字段保留原名，诊断日志和明确标为原始数据的视图保留技术信息。

同时修正了几处显示语义：

- “运行中 + 部分异常”使用黄色提示，不再因为进程运行就显示绿色。
- 缺少指标显示“—”或“待确认”，不据此宣称正常。
- 上传任务运行、业务就绪和接收确认分开统计；有历史确认记录不代表本次上传已经成功。
- Webull “暂无数据”不再被显示为“数据过期”。不会仅依据无数据就断言休市或故障。
- 时间使用本机时区显示，并标注本地时间；快照头部悬停可查看原始时间。
- Webull 操作按钮改为多行布局，减少小窗口横向拥挤。

## 验收结果

- 本地 `machome-hub-ui`、`hub-ui-preview` 和 `tst-module-pages` 编译成功，见 [build.txt](build.txt)。
- 界面测试 **17 项通过、0 项失败**，见 [module-tests.txt](module-tests.txt)。涵盖既有份额映射、控制按钮信号、详情订阅、历史处理，以及新增的缺失数据、异常颜色、无行情文案、中文显示和本地时间检查。
- 核对既有控制操作字符串序列未变，见 [control-action-check.json](control-action-check.json)。这只是辅助静态检查，不等于验证了交易业务；交易接口未执行。
- 使用真实页面组件及主窗口，通过明确的离线预览启动模式渲染先前保存的 R4 历史快照。该模式在创建 HubClient、后台线程和服务连接前返回，没有业务连接。
- 总览和四个服务页均生成 **1440×940、1120×760** 两种尺寸的截图。较小窗口纵向内容可滚动，关键指标保持在前。截图中的业务数值来自历史快照，不代表目前运行状态。

## 主要源码

- `app/src/ui/ServiceOverview.h/.cpp`：只读的服务概况组件，消费已有快照。
- `app/src/ui/UiText.h/.cpp`：集中管理中文显示、状态颜色和界面样式。
- `app/src/ui/ModulePages.h/.cpp`：概况页集成，保留原有业务页与操作连接。
- `app/src/ui/MainWindow.h/.cpp`：运行总览、中文名称、明确的离线预览启动方式；正常启动仍使用原有连接流程。
- `app/tests/ui_preview.cpp`：离线视觉验收工具；不启动业务服务。

本地编译产物在 `app/build-acceptance-20260905/Machome 四合一运行中心.app`。这是本地完整构建产物；生产部署采用以已验收 R4 为基线的界面补丁，没有整体替换后台构建。
