# 五合一 v1.1.0：本地 IOPV 与 L1 保留

新版由原目录工作树复制，包含未提交文件，来源 SHA-256 见 baseline.json。原目录及原独立 IOPV 服务没有修改。

## 运行结构

PremiumAEngine 保留 CoreServer、TGW helper 和 LegacyL1Server。包内 machome-iopv-server 由 Agent 托管，不使用独立 LaunchAgent。开启 local_iopv_enabled 后，IOPV 从本机 L1 分批订阅（每连接最多200只），复用原订阅引用计数/释放宽限期。行情接口未添加或重定义字段；保留19195 NDJSON v1及原默认/热/动态清单。

IOPV 子进程异常每10秒重启；停止估值计算使用网页“暂停计算”，不会关闭行情连接。Agent 停止会终止自己托管的 IOPV；父进程意外退出时 Go 检测父PID变化并退出。Qt 页面使用 WKWebView 展示同一份 Go 网页，服务启动前页面会自动重试。远端网页写管理操作仍仅限本机。

本地 IOPV 启用时，国内行情延长到15:01前以接收15:00收盘报价；港股延长到16:09前以覆盖16:08分钟。没有将这一调整扩展到交易信号时段。

## 估值及信号接口

- Go REST/SSE/分钟档案保持 intranet-iopv.v1。
- 沪市用上海港股通、深市用深圳港股通；网页双方向结算估值保留。
- 默认监控信号口径 midpoint；可在配置选择 settlement_buy、settlement_sell。网页的买卖情景按钮只改变展示，不修改监控配置。
- 原 SignalEngine 阈值与时间窗口复用，但计算输入为本地估值；本地缺价、陈旧、停牌确认或暂停等情况不回退交易所IOPV。中间价信号独立于结算FX可用性；结算口径额外遵循源 actionable 门禁。
- PCF版本、服务run_id、交易日、口径、模型变更会重置窗口；本地快照超过12秒清空该证券信号窗口。
- 原19195和8421/v2行情字段仍表示原始行情。新的本地信号走 `/ws/v3/local-iopv-signals`，携带 valuation_source、valuation_basis、完整 valuation 依据。原生界面的信号事件也保留这些信息。旧v2不混发本地信号，其上升量在本地模式下不再提供。
- 新模块仅向质量通过且当日可定价的基金提供本地估值，暂缓清单不自动加入。

## 配置与部署

用 app/scripts/prepare-local-iopv-config.py 从现有实际配置生成新文件，保持其他模块原值、账号引用、观察清单、热清单等。工具拒绝覆盖源文件或现有输出。上线前先用新包Agent --check-config 验证，再按原install/rollback流程切换。

生产设 local_iopv_enabled=true、iopv_port=18680、iopv_listen=0.0.0.0:18680、iopv_web_url=http://127.0.0.1:18680/。测试配置在 runtime-candidate/modules.json，使用18681网页、19196 L1、18422摘要及/private/tmp/machome-v110-candidate内的独立数据。test_iopv_l1_address 仅在 test_mode 下生效，用于候选版从现有machome L1取行情；生产默认始终本机L1。

运行数据不放入发布包。上线的数据目录为原premium根下local-iopv；回滚不覆盖旧数据库。本地独立模块的历史档案不会默默复制覆盖，需要时另行做可审计历史导入。
