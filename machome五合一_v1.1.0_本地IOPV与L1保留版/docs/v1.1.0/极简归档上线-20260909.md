## 存储语义

每基金每日一个版本化 IOPZ1/zlib 压缩块（WITHOUT ROWID 复合主键），块内 ETF 以 ×1000 整数、三种 IOPV 以 ×10000 整数保存。读取恢复原 Point API 结构。NULL、三种溢价率可用性分别保留；仅原先可用的溢价率按归档价格重算。收盘后失效值不因归档重算而恢复有效。

分钟档案不再保存五档盘口、五档派生溢价率、逐分钟 HKD/CNY 资产小计。保留基金、日级 PCF 哈希、份额和现金信息、来源/模型、成分覆盖、缺失/停牌/陈旧列表、各时间戳、原因标记。共享重复文本由跨分钟压缩消除。实时报价内存和 API 中的五档、资产值、精度不受该归档处理影响。

FX 原始字节按小时压缩，无损保留全部快照和时间，不对相同报价但不同状态去重。同一时间戳保持首次记录规则。PCF 原文独立版本头压缩，启动缓存恢复和抓取失败回退均兼容旧原文和新压缩原文。

分时图 tooltip 同步显示 ETF 三位、IOPV 四位。四舍五入仅发生在历史落盘阶段，历史 IOPV 最大误差 0.00005 元/份，实时信号使用原精度。
