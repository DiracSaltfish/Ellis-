原始来源为腾讯当日分钟接口（港股、沪深 ETF，不复权的提供方分钟标签）、正式机当日 PCF 和 1navs 港股通历史预估汇率接口。原始响应已下载到 runtime-production/backfill-20260909/raw，并保留每个请求的 URL、抓取时间及 SHA256。

- 750 个标的响应均为 20260909；1300 等提前出现的占位分钟未纳入午间回填。
- 当日固定 HKD/CNY 中间价为 0.86418，来源保留在 fx-snapshot.json 的 central_parity。
- 上海基金使用 shanghai 历史，深圳基金使用 shenzhen 历史。买入港股采用预测卖出汇率，卖出港股采用预测买入汇率。
- 同分钟精确匹配，不向前填价格、不用当前汇率替代历史汇率、不补造五档数据。
- 发现 00853.HK、02252.HK 等停牌证券被提供方扩展为今日零成交量的固定价格序列；所有累计成交量为零的分钟均排除。即使源日期是今天也不将这些价格当作有效成交。
- 预估汇率要求当日、对应分钟、源报价不在未来且不超过 3 分钟；cfets_unavailable 留空。reference_only 可展示历史参考线，但不可用于实时信号。

- 每条回填记录 mode=historical_reconstruction，eligible_for_signal=false，包含 PCF 哈希、来源分钟、汇率时刻和质量原因。
