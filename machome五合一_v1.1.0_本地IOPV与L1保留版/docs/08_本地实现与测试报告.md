# 08 本地实现与测试报告

> 历史说明：本文记录的是旧 adapter/sidecar 迁移阶段，测试数量和交付形态已过时。当前四个原生 Engine、最终测试证据、时间基线修复与剩余生产 gate 以 [13 四模块原生整合最终审查报告](13_四模块原生整合最终审查报告.md) 为准。

## 1. 结论

四合一工程已完成可运行实现，不再只是页面原型。本地已经验证 GUI、Agent、四个真实协议 adapter、Webull Python 桥、双 QMT、控制状态机、审计和交付脚本。当前产物的准确定位是：**可交给 machome 做 shadow 与真实交易日验收的 1.0.0 迁移候选版**。

本地 mock 能证明协议、线程隔离和控制链正确工作，但不能证明 Wind/TGW/WebTrade/IB、交易所时段、生产数据量或系统通知权限在 machome 上完全一致。因此生产 gate 仍以 06 清单和 09 手册为准。

## 3. 业务覆盖

### Upload

- 网站 liveness 与业务 worker freshness 分开显示；
- 读取原有 health JSON，显示 source/PID/stage/last success/error；
- `workers_expected` 显式控制盘外 scheduled-idle，避免空目录误判绿色；
- 网站及原 Vue 二/三级页面继续使用外部浏览器深链；
- owner 阶段按精确 LaunchAgent label 独立启停，不按进程名模糊匹配。

### 溢价率 A 端

- 8421 summary/signal/status/sync/raw snapshot，并用独立 `/ws/v2/detail` 连接提供最多 4 个标的的实时十档详情；
- 19195 hello/status/ping、订阅状态与五档数据；
- 观察清单、L1 热清单带 ACK 的原子更新；
- 实时拉升、运行状态、原始详情；
- JSONL 历史按日期/标的/模型后台筛选，后台导出 CSV，不阻塞首页。

### Webull

- v2 live/ready/status/symbols/book/clients/stream；
- session/sequence/gap/stale/full-replace/decimal-string 严格校验；
- schedule mode、collector start/stop、restart browser、open login 五项控制；
- 控制 runner 与旧入口共用 `gateway.lock`，防止双 collector；
- `open_login` 经 Qt 主线程调度，并处理运行时刚启动的竞态。

### 实时申购赎回

- 6787 health/snapshot/history/watchlist/PCF 与 WS change/status/heartbeat；
- 按真实嵌套 `values / pcf / opportunity` 结构展示 13 列主表；
- 观察清单和名称维护，monitor/Wind/PCF 控制；
- PCF 二级页保留摘要、成分、QMT1、QMT2 四个 tab；
- QMT 两链独立连接、全量/增量校验、心跳、断线、1 MiB 限制；
- 只有 welcome + orders + positions 完整同步后才允许固定 qty=1 的申购/赎回，下单要求表格双击和全局二次确认，5 秒节流。

## 4. 控制与安全语义

- wire schema 分为 `module.status.v1`、`module.event.v1`、`module.control.v1`；
- 每条 mutation 都带 command ID、requested_at/by、reason、deadline 和 expected control revision；
- telemetry sequence 与 control revision 分离，快速行情不会制造虚假 stale revision；
- exact replay 返回缓存结果；同 ID 不同参数返回 `command_id_conflict`；
- mutation 缺少修订号或页面已过期时拒绝；
- 生命周期命令只在 `ownership=owner && control_enabled=true` 时执行；
- 默认示例全部是 `shadow + control_enabled=false`；
- Agent 管理面使用 0600 Unix socket 并校验 peer UID；帧和慢客户端队列有界；
- Webull 控制口当前是 loopback + Bearer。单用户可信 machome 可用；若主机存在不可信本地账号/进程，应保持 mutation 关闭，升级到 peer-UID UDS 或双向 HMAC 后再开。
