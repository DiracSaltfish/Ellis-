# 独立服务运行与验收

## 访问入口

- 估值网页：http://127.0.0.1:18680/
- 本机管理：http://127.0.0.1:18680/manage
- 同一内网查看：http://192.168.1.23:18680/ （当前本机地址；网络变化后随地址更新）
- 独立 macOS 管理窗口：`dist/内网IOPV管理.app`

管理窗口使用本机网页界面，提供刷新PCF、重连行情、暂停/恢复计算、数据库完整性检查。关闭管理窗口不停止后台服务。管理写操作只接受本机，内网其他机器可读取估值/分钟API。

服务 label 为 `com.ellis.intranet-iopv`。启动配置仅属于此独立模块，不修改五合一配置、监听端口或策略。

```sh
cd '/Users/ellis/工具程序开发/内网IOPV计算'
./scripts/service.sh status
./scripts/service.sh stop
./scripts/service.sh start
./scripts/service.sh restart
python3 scripts/backup.py
```

stop 停止并卸载本次运行的用户服务；start重新加载已经安装的plist。管理页的“暂停计算”保留行情和存储服务，网页/API明确标记暂停和估值过期。“重连行情”只重启本模块C++读取器，不踢出其他账号会话。

## 实际组成

Go `iopv-server` 管理120只候选、当日PCF、FX、共享行情缓存、3秒三组C++估值、分钟SQLite、REST/SSE和网页。C++ `iopv-feed` 复用只读拷贝的现有TGW传输库，独立会话强制 `force_logout=false`。源完整帧/增量帧按会话隔离，只有完整帧后才接受增量，拒绝乱序、结构错误及非法报价。

源价格除以1e6，盘口数量除以100为股，不按港股每手数量再次换算。源时间保留到毫秒。行情没有接收时不得伪装成0价。没有有效当天成分价时整篮估值为空；同日陈旧成交价可以显示篮子参考值，同时列出陈旧成分并禁止signal eligibility。不会使用交易所IOPV做fallback。

用户已明确的通道规则现已固定：`.SZ`用深圳港股通预测结算汇率，`.SH`用上海港股通预测结算汇率。API同时保存买入港股和卖出港股两方向，界面选择其中一条与中间价对照。中间价有效时，即使结算数据失效也继续计算中间价分支。

每5分钟尝试更新当日PCF，启动立即尝试；按交易所响应的交易日期严格校验。失败可以使用已归档且同日校验通过的PCF，禁止跨日沿用。每分钟更新网站FX JSON。PCF、汇率、估值分别保留版本或时间戳。日期切换后的旧篮子/旧报价不会变成新一天的估值。

所有候选持续订阅，不轮流取消股票订阅；分组轮换的是ETF篮子。各组按成分数量平衡，0/3/6秒运行0/1/2组，错过节拍不补积压任务。

## 分钟落盘

数据库：`data/iopv.sqlite`，WAL、FULL同步、有界HTTP超时、唯一键。保存：

- minutes：基金+日期+分钟唯一；三种IOPV、ETF价、三种溢价、FX、PCF版本、源时间、质量、运行ID。
- pcf：原始PCF、SHA-256、交易日、抓取时刻；同日改版新增版本。
- fx：每次网站快照及来源生成时刻。
- events：管理动作与PCF加载结果。

分钟关闭后写入该分钟最后一次计算结果，记录实际计算时刻，**不是把每组值重新标记为同时计算**。重启后同键幂等更新为时间更晚的一条，不用旧数据覆盖新记录。正常退出会落下当前部分分钟，后续该分钟采样可以更新它。

## API

所有读取接口不包含账户配置。时间为带时区ISO8601，IOPV为元/份，汇率为元/港元，溢价字段为百分数（1表示1%），空值null。

```text
GET /api/v1/health
GET /api/v1/snapshots
GET /api/v1/stream                         # SSE，每3秒发布最新全量，断线自动重取
GET /api/v1/components?symbol=513090.SH     # PCF成分及对应源报价，用于核账
GET /api/v1/minutes?symbol=513090.SH&date=2026-09-09
GET /api/v1/dates?symbol=513090.SH
GET /api/v1/export.csv?symbol=513090.SH&date=2026-09-09
POST /api/v1/manage/{refresh|reconnect|pause|resume|check}
```

管理POST需本机来源及 `X-IOPV-Manage: 1`，同源校验；管理按钮已封装。SSE始终发布全量快照，所以重连不依赖漏掉的增量。每条基金记录带run_id和sequence，客户端可检测服务重启；写超时5秒，慢客户端不会阻塞计算。

snapshot字段：midpoint_iopv、settlement_buy_iopv、settlement_sell_iopv；ETFPrice仅正常国内交易时段有效。fx_actionable为源模型状态，eligible_for_signal同时要求PCF、完整报价、成分新鲜度、国内ETF报价和汇率门禁。暂停或估值超过12秒时API取消信号资格并清空实时ETF溢价字段，历史NAV保留但明确过期。它是数据门禁，不是下单建议或交易指令。

## 本轮验收重点

1. 网页选513090，比较两种NAV与两个汇率；切换买/卖情景，确认通道是上海。
2. 选159217，确认通道自动为深圳。
3. 管理页检查120只PCF、750订阅、接收帧数和落盘行数增长；查看缺失/陈旧成分列表。
4. 等待跨一分钟，导出CSV并重开日期，确认记录可回读。
5. 暂停计算后页面显示暂停/过期；恢复后新序号继续。
6. 重连行情后旧会话增量缓存被清理，新完整帧陆续恢复；少成交标的重新热身可能需要时间。
7. 重启后台服务，历史分钟仍保留，run_id更新并恢复接收。

## 尚未跨过的边界

没有接回五合一，没有替换其交易所IOPV输入，没有修改交易策略，没有发送任何订单或申赎。没有把缺失的停牌成分用原质控夹具的旧价回填；这些基金暂时不可计算完整实时篮子，管理界面会列出原因。

本轮是运行中的独立验收模块，不把短时间联调称为整交易日长稳验证。下一次验收可覆盖午休、15点、16:08及隔日重新开盘；这些边界已有逻辑测试，但实际市场时段需要自然到达后观察。
