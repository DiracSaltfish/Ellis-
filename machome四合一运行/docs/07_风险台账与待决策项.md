## 2. 当前状态判读

本轮只读快照不能替代盘中验收：

- Upload：网站与进程组运行；日终同步完成。health monitor 历史注意项待复核。
- Premium：三进程运行，上一交易日订阅/退订流程符合计划；当前盘外空闲。
- Webull：API live，auth 已验证，盘外 collector stopped/no_data 符合计划。
- 实时申赎：服务运行，盘外 Wind 已退出；重复 `EINTR` 需确认是否影响盘中采集。

因此当前没有依据把四组程序判为“已全部业务健康”，也没有发现需要本轮立刻停机的证据。

## 3. 当前实现决策

为完成本轮实现，已经采用以下可回退默认值：

1. Hub UI 只在 machome 本机运行；远程管理不复用当前 socket，未来需独立 mTLS 方案。
2. Upload 网站默认外部浏览器打开，不引入 QtWebEngine 依赖。
3. Premium B 端交易不属于本次四合一，只迁 A 端并继续保持 A/B 安全隔离。
4. 业务暂停和服务启停分开；服务级动作只在 owner 模式显示并全局二次确认。
5. Agent 已具备 lifecycle owner 能力，但默认 shadow；稳定后才逐模块交接。
6. 交易日规则保持原业务语义；正式节假日日历作为独立兼容升级，不能悄悄改变行为。
7. UI 使用 Qt Widgets，适配现有表格、二级窗口和桌面运维习惯。

## 4. 不建议的方案

- 一个巨型进程同时链接 C++ Qt、PyQt、Python interpreter、浏览器和 TGW SDK。
- 将四套旧窗口做 macOS 跨进程 QWidget 嵌入。
- 把 8421/6787/18765 任一数据端口扩展成通用 shell 管理端口。
- 用进程存在/端口开放作为唯一绿色状态。
- 一次替换四个 owner 或一次搬完全部业务数据。
- 为追求“原生 C++”优先重写 WebTrade/Wind 私有链路。
