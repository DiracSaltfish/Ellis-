# 日内三序列与当日净申购因子研究

## 本轮用户指定口径

- 先不估计隐藏的双边申赎数量，目标为当日大量**净**申购的条件。
- 回测2025-07-01至2026-06-30；虽然PCF可到2026年8月，本轮保留用户提出的截至6月的一年。
- 日内固定使用当日最终结算汇率、当日中间价。结果是这一已知最终汇率条件下的关联研究，不是盘中汇率预测或套利实收实付回测。
- 网站日期直接对应当日净份额变化，不做T+1平移。当天盘中计算的因子与当天盘后份额净变化关联。
- 股票和ETF分钟数据在machome本机处理，文件和代码位于该机的同名研究目录；本机保存代码、来源与小体积研究结果。

## 序列和质量规则

IOPV = (港股成分数量×分钟收盘价之和×汇率 + 预估现金差额 + 真实固定现金替代项) / 最小申赎单位。

与现有 `services/iopv/core.cpp` 一致处理港元资产、人民币现金与份额单位；忽略159900“申赎现金”汇总行，防止与成分价值双算。CSV“退补”证券按数量×价格估值，不再叠加预收替代款。固定替代金额缺失、未知成分、不完整PCF、无净份额标签等保留排除原因。

分钟时间戳统一延后一分作为保守可用时刻。同日仅向前填充最多5分钟，无未来补值、无跨日补价；午休不计入溢价持续分钟。非交易日、缺少实际结算率或中间价的日期不强行拼接。ETF闭市后的价格设空，保留港股估值轨迹。

SH基金暂以沪港通汇率、SZ基金暂以深港通汇率重建。这是计算通道假设，不代表已证明基金实际交易只走该通道。缺少基金实际路由配置时，两种通道价格的细微差异仍属于估值误差。

原始分钟价以独立复权因子另存的数据结构和PCF净值复核作为未复权口径的交叉检查；仍未逐次核实所有公司行动。样本的收盘字段一般止于16:00，不能宣称完整重建收盘竞价最终成交。主因子覆盖ETF与港股同时交易的全天有效分钟；15点后的港股变化另存诊断列，不混入ETF价差。

按基金日保存分钟表到远端 `results/series/YYYYMMDD.parquet`。字段包括ETF价、两种汇率IOPV、额外卖方向IOPV、基础港元资产和现金。保留此前准备的昨日结算基线列，仅作审计，本轮因子使用当天最终结算率。

## 标签、因子与评估

每个基金-日期一行，使用当天全部有效重叠交易分钟。build_panel.py保留的早期分时点输出会被aggregate_daily.py替换；最终分析只读取全天面板。

主标签“大量净申购”预先定义为：当日净增至少10篮子，且净增份额至少为前一日份额的0.5%。同时报告任何净申购概率、净赎回概率、净篮子中位数，以及5篮子/0.2%、20篮子/1%的敏感性，避免把不同规模基金的绝对份额直接混比。

候选因子：

1. ETF相对两种IOPV的即时/均值/最大溢价、15分钟变化。
2. 正溢价持续比例、超过30/50基点的持续比例、正溢价累计面积。
3. 全天成交额/昨日基金资产规模（使用成交额，避免股票股数与ETF手数混淆）。
4. ETF涨幅、篮子涨幅、汇率引起的两种IOPV间距。
5. 前一日和此前5个交易日净流量、昨日基金规模、申赎开放状态。
6. 全天溢价分位数、标准差、最长连续溢价时间、穿越次数、成交额加权溢价、首尾30分钟变化、路径斜率及跟踪误差。

固定时间切分：2025年7—12月训练、2026年1—3月验证、2026年4—6月留出测试。同一天所有基金处于同一分段，禁止随机拆分制造信息泄漏。

单因子分桶边界只在训练期确定。规则从预列网格中按验证期大量净申购命中率挑选，要求至少100个验证样本、10只基金、20个日期；留出测试不再调规则。逻辑回归和小型梯度树只在训练期拟合，按验证PR-AUC选模型，以验证评分90%分位数固定筛选阈值后检验末季。

当前标的列表用于回看历史，会有存续标的选择偏差；新成立基金只使用实际存在的数据，不补造历史。多基金同日相关，因此命中率区间按日期聚类自助抽样，不按基金日独立抽样。

由于使用当日最终汇率，时间切分只能检验跨期稳定性，不能消除该汇率在盘中的不可得性。此次不回答实际申赎套利收益，也不把净份额量当成双边申购总量。

## 复现

代码唯一维护源在本机本目录，同步至machome同名目录运行。原始数据只读。

```sh
ssh machome
cd /Users/ellis/工具程序开发/港股通ETF轧差套利分析
.venv/bin/python factor_research/prepare.py
OPENBLAS_NUM_THREADS=1 .venv/bin/python factor_research/build_panel.py
.venv/bin/python factor_research/verify_inputs.py
OPENBLAS_NUM_THREADS=1 .venv/bin/python factor_research/aggregate_daily.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 .venv/bin/python factor_research/analyze.py
```

最后运行 `.venv/bin/python factor_research/make_notebook.py` 可生成并执行研究复核笔记。

脚本输出原始输入缓存、每日排除原因、完整分钟序列、因子面板、时间切分基准、单因子分桶、规则检验、模型检验、标签敏感性和分基金/分月份结果。
