# 61U去了哪里：发现58.43U整篮子形态卖出，但不能把成交形态当成份额来源

对象：520600.SH，2026-09-02。1U＝50万份。本次继续使用原始L2、当天PCF与1navs当日份额标签，进一步追踪每个卖单的买方订单，并复核原数量模型。未修改原模型，未为拟合61U调整整数U容差或选择成交组合。

**本次找到了比“31笔1U主动卖单”更完整的证据：截至14:45，65个具有整U或近整U形态的卖单，累计实际成交58.4322U＝29,216,100份。其中18.1086U是被动卖出。** 这些卖方成交真实存在，已按交易所订单号去重，并能逐笔定位对应买方订单。它们与“新增份额在二级市场出售”的解释相容。

但是，58.43U与实际净增61U的接近，**不是已经追踪到95.8%的新增份额**。L2没有账户、持仓来源或一级申赎时间；同样形态也会来自旧持仓换手。买方还有14.2220U同类成交，机械相减变成44.2102U；历史检验表明这个差额也不能直接当成净申赎量。

数量模型的3.59U更不是“只找到3.59U申购”。它是从33个统计因子回归得到的结果，没有逐单认领申购篮子的步骤。本例极端程度、因子对执行形态的压缩，以及原回归目标的压缩共同限制了输出；不能用“其余57.41U交易丢失了”解释误差。

## 1. 从31U扩展到58.43U：这次补上了什么

固定沿用上次整数篮子规则：数量接近正整数倍U，误差不超过0.01U＝5,000份。先按原始数量是否已知分组，再按实际成交量汇总，绝不重复累计同一卖单。

| 不重叠的卖单类型 | 有实际成交的订单数 | 实际成交量 | 含义 |
|---|---:|---:|---|
| 原始量未知，主动成交恰好500,000份 | 31 | 31.0000U | 上次最醒目的31笔整U主动卖出 |
| 原始量未知，主动成交496,800份 | 2 | 1.9872U | 同一固定容差内的近1U主动卖出 |
| 原始委托确认500,000份 | 23 | 14.8036U | 部分主动、部分被动；只累计成交，撤单不计入 |
| 原始委托确认1,000,000份 | 5 | 8.1142U | 2U原单，可以分成主动成交与挂出余量 |
| 原始委托确认496,800份 | 4 | 2.5272U | 接近1U的已知原单，按实际完成数量计 |
| **合计** | **65** | **58.4322U** | **29,216,100份二级市场卖方成交** |

全部在14:45以前出现，全天同口径仍是58.4322U。98个接近整数U的已知原单中很多没有成交，不能把申报数量全部计入这张表。

按执行方式进一步拆开：

- 原单未知的近整U主动成交：32.9872U。
- 原单已知的近整U订单，主动成交部分：7.3364U。
- 同一批已知原单，被动成交部分：18.1086U。

三项相加58.4322U。后两项说明，**只统计主动成交恰好1U，会漏掉“原单本来是1U/2U，但只主动成交一部分，剩下挂卖”的行为**。整U原单的判定与整U主动成交的判定必须分开。

496,800份为何反复出现目前不能确定，不能猜成扣费、同一机构指令或特定算法。将其完全排除、只接受严格整数U后，卖方成交仍有53.9178U，现象并非完全依赖±1%容差。

## 2. 这些卖方成交具体去了哪些订单

58.4322U对应的逐笔成交，买方交易所订单号去重后有**5,027个**。这能确认的是二级市场成交对手，不能确认5,027名投资者，也不能把买方订单视为最终持仓账户。

- 4,735个买方订单从这批卖单中接到不超过10,000份，合计接到3,168,300份，占10.84%。这里指从选中卖单接到的数量，不一定是买单原始总量。
- 70个买方订单各接到超过100,000份，合计18,158,400份，占62.15%。**小额买方订单数量很多，但接货份额主要集中在较大订单，不能据笔数断言都是散户承接。**
- 最大一个买方订单9314366累计接到756,900份；前十个买方订单合计接到5,211,400份。

两个典型执行路径：

**卖单5893370：2U原单被拆成两种成交方式。** 09:55:59.500先主动卖出755,300份，逐笔委托显示剩余244,700份挂出；后者在09:55:59.540前被动成交完。程序重建原单为1,000,000份，两部分恰好守恒。这是一笔2U卖方供给，不能只把244,700份当成原单，也不能只寻找“主动成交正好1U”而漏掉它。

**卖单6855380：1U被动供给在资金流图里表现为主动买入。** 10:03:26.560挂出500,000份，10:07:30.960由买单7338010吃掉500,000份。卖方卖出完整1U，但成交BS为B。买单7338010当时总共主动买了1,000,000份，属于2U主动买单。因此，主买资金流和潜在申购卖出可以同时存在，不能把二者当作互斥信号。

“去了哪里”在当前数据下能追到这里：**从这些卖方订单成交到了这些买方订单。** 买方随后是否又通过另一订单卖掉、是否赎回、是否留仓，因缺少账户关联而无法继续连接。订单号相邻或时间相近也不足以建立这种连接。

## 3. 为什么58.43U不能直接算成61U的来源

### 3.1 全市场成交守恒与基金份额变化是两个账

截至14:45，每一笔二级市场成交都有买卖双方，因此：

`二级市场卖出总量 = 买入总量 = 312.4290U`

这里是总成交量，并非买卖各计一次后相加。全部卖方成交可无重叠拆为：

| 卖方订单类型，按表序优先归类 | 主动成交U | 被动成交U | 总成交U |
|---|---:|---:|---:|
| 原始数量确认且接近整数U | 7.3364 | 18.1086 | 25.4450 |
| 原始量未知、主动执行接近整数U | 32.9872 | 0 | 32.9872 |
| 其余主动成交至少0.5U的大单 | 37.3914 | 0.5294 | 37.9208 |
| 其余原始量已知且至少0.5U的订单 | 5.7304 | 34.4748 | 40.2052 |
| 其余订单 | 83.8036 | 92.0672 | 175.8708 |
| **总计** | **167.2490** | **145.1800** | **312.4290** |

表的前两项构成58.4322U，其他组仍有253.9968U，不能排除其中也包含拆得更小、不按整篮子卖出的新增份额。

对于所有持有人的总份额，另一条守恒关系是：

`收盘总份额 − 昨日总份额 = 一级申购 − 一级赎回 = 61U`

二级市场买卖仅改变持有人，合计买入和卖出相互抵消，不会改变基金总份额。**61U无需等于某一类L2成交量，也无需全部在当天卖出。**

### 3.2 同样的L2可以对应不同新增份额去向

存在至少两类当前数据无法区分的解释：

- 某些参与者申购后，通过整U卖单、部分主动＋部分被动、拆单等方式售出；新增份额最终由其他持有人接走。
- 参与者先出售原有库存，随后申购补回；或者新增份额直接留仓，而当天观察到的卖单全部来自旧份额。

昨日已有235,868,000份，甚至高于当天164,412,500份总成交。仅从总量看，完全有足够旧份额承接全日卖出；这并不证明实际如此，但说明不能由交易量强迫推出“这些成交一定是新增份额”。同样也不能因没有找到足够整U卖单，就认为新增份额必须留在某个账户。

收盘可见卖单剩余14.4598U只是**已识别订单在订单簿上的未成交量**，并不是持有人剩余库存，不能据此推算61U中有多少未卖。

### 3.3 买方相减也不能解决身份缺失

使用同一整数U标准，买方实际成交14.2220U。卖方58.4322U减去买方14.2220U得到44.2102U。两组选中订单之间有5.5074U交叉成交，外部成交分解为：

`选中卖单卖给其他买单52.9248U − 选中买单向其他卖单买入8.7146U = 44.2102U`

交叉量已核验守恒，但它仍然只是按订单形态选出的二级市场净供给代理。我们不知道选中买方是否为赎回参与者，更不知道买卖两组选中订单是否属于相同主体。因此44.21U不是“更正确的一级净申购量”。

58.4322U与61U相差2.5678U＝1,283,900份，**不能把这个差值直接命名为“剩余未卖出的新增份额”**。

本次没有寻找任意组合来贴近61U。容差和替代单位沿用原研究定义，将参考单位分别替换成40万、60万、65万份，用完全相同的“已知原始量或未知原单的已执行量”规则重算：

## 5. 数量模型为什么压到3.59U

### 5.1 数量模型预测的是净增幅，再换算份额

原模型输入33个基础及L2因子，回归目标是`asinh(当日净增幅百分比)`，输出后经过`sinh`反变换，再乘昨日份额换成数量。

本例输出0.760829%的净增幅，对应：

`0.760829% × 235,868,000份 ÷ 500,000份/U = 3.589105U`

真实净增幅是12.930961%，所以误差首先发生在对增长率的统计预测上，单位换算没有把61U算错。

### 5.2 训练数据对本例这样的增长极端稀疏

原拟合集2,293条基金日记录中，净申购440条、净赎回773条、不变1,080条。净增幅99分位只有4.87%，达到本例12.93%及以上的仅4条。

520600自身的16个训练日，只有2个净申购日，最大14U、净增幅1.58%；其当时昨日份额约4.38亿—4.51亿份，本例为2.36亿份。单位仍然都是50万份，并不存在PCF单位变更造成的61U错算。该模型是跨基金共享模型，不是只对520600训练；但这些分布说明它很少见过相似强度的净增长。

每棵树最多7个叶子、每叶至少50样本并有正则化，更倾向从一组样本中学习稳定响应。它没有理由把61U这样罕见的结果自动外推出去。本例双估值差88.65bp还超过训练范围上限77.26bp，进一步增加跨时期失配。

### 5.3 数量模型对醒目的订单证据响应很弱

上次报告解释的是**净申购概率**。这次另对**数量点估计**做了8组因子的精确分组贡献分解，使用相同32条训练背景、全部256种组合。所有结果先换成当前基金规模下的U，严格可加总：

| 数量模型分解 | U |
|---|---:|
| 背景样本平均预测，按本例昨日规模换算 | −0.9749 |
| 溢价水平与走势 | +2.6235 |
| 溢价回落期间成交 | +1.5650 |
| 整U短时成交簇 | +0.6851 |
| 整U主动订单 | +0.2878 |
| 整U被动卖单 | +0.1304 |
| 主动差额 | +0.0029 |
| 大额主动订单 | **−0.0512** |
| 历史份额、规模与换手 | −0.6795 |
| **最终预测** | **+3.5891** |

这反映旧数量模型的响应，不是61U真实申购的来源分解。尤其大额主动订单对点估计几乎无正向作用；整U原单拆成主被动后，分别被压成少数金额占比、短时簇比例等特征，原模型没有直接保留“65张有成交的整篮子形态订单，共卖出58.43U”的完整数量结构。

因此模型既可能看到了偏向申购的方向信号，又只给出很小数量。这不是C++撮合漏掉了几十U；成交量已独立与行情累计量核对一致。

### 5.4 去掉目标压缩，仍然解决不了

做了一个固定对照实验：保留原训练日期、特征、所有树参数，仅将训练目标从`asinh(净增幅)`改为原始净增幅。没有使用9月2日训练，也没有保存覆盖原模型。

| 评价范围 | 原模型 | 不压缩目标的诊断模型 |
|---|---:|---:|
| 9月2日预测 | 3.59U | 7.72U |
| 原验证集数量MAE，596条 | 13.97U | 18.76U |
| 原测试集数量MAE，592条 | 13.41U | 17.69U |

正向大额样本在压缩尺度上被降低了极端影响，反变换也不等于直接预测原尺度条件均值；这与本例输出偏小有关。但去压缩后本例仍少估53.28U，原测试误差反而增加约31.9%。**不能通过简单放大预测、取消变换或按61/3.59乘一个倍数来修复。**

### 5.5 不是61U全在14:45以后卖出造成的

14:45以后总成交只有15.9452U，其中连续竞价15.4266U、收盘集合竞价0.5186U。即使这段每一笔卖出都来自新份额，也不足以容纳61U全部出售。更重要的是，前述58.43U卖方形态已经全部在14:45之前出现。

但不能据此反推实际申购发生时间：也可能先卖库存再申购补回，或晚些时候申购并留仓。因此“尾盘申购”作为一级市场行为并未被排除，只是“61U全在末15分钟二级市场卖出”不符合已见成交总量。

## 6. 对下一版模型的具体含义

建议把当前纯统计预测改成“订单执行证据＋条件概率/数量估计”两层，并保留未知份额来源。

1. **执行证据层单独输出可核验的量。** 例如本例：严格整U卖出53.92U、容差内58.43U、其中被动18.11U；其它大额卖出、对手承接集中度及撤单分别记录，不把它们直接命名为申购份额。
2. **不能机械用整U买入抵扣赎回。** 1月12日已给出反例。买卖方证据应分别与当时结算溢价、中间价折溢价、PCF限额、成交完成比例关联，由历史标签学习，而不是假设所有买方大单都会赎回。
3. **数量目标需要显式处理大量0和少量极大值。** 可以分别估计发生净申购的概率、发生后数量分布，并与当前单回归器比较；正向大净量样本要有跨日期覆盖，不能只补本例。是否比原模型更好必须同时看原测试集和新增未参与设计的日期。
4. **识别条件变化时限制置信度。** 如本例汇差超出拟合范围、相似大净增样本极少，输出应显示“数量证据强，但数量映射未经充分校准”，而不是让3.59U显得精确可靠。不能因观察到58.43U便临时把净申购概率上调到90%以上。

当前最有依据的解释是：**9月2日在14:45之前，市场中已经有接近61U量级、具有篮子尺度特征的卖方供给，经主动和被动两种方式被买方订单承接；原统计模型没有将这种结构映射为大额净申购。** 这些成交中究竟多少源于当天新增份额、多少是原库存、多少随后被再次交易或赎回，当前L2无法唯一识别。
