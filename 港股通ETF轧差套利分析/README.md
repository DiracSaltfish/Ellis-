# 港股通ETF轧差套利分析

研究日期：2026-09-12。所有后续研究、参数、实验与代码保留在本目录。

当前交付：结算情景模型，以及2025年7月至2026年6月的全天路径因子研究。已重建三组分钟序列、匹配当日净份额变化，并完成时间留出检验。详见 [首轮因子研究](factor_research/首轮因子研究.md) 与 [可执行复核笔记](factor_research/研究复核.ipynb)。

- `研究底稿.md`：数学机制、黑盒可识别性、预测和验证路线。
- `model.py`：独立、无外部依赖的情景计算器，支持自己的双向数量和联合概率情景。
- `test_model.py`：数学性质与边界验证。
- `evidence/`：读取的本地网站原始JSON和来源记录。
- `example_results.json`：合成价格和流量下的演示结果，非真实交易收益。

在本目录运行：

```sh
python3 model.py
python3 -m unittest -v
```

## 持续保留的用户条件

1. 用户已经实测：当日申购份额可以立即赎回，并且申购、赎回分别结算。这两点作为研究已知条件，不重复索取证明。
2. 各基金规则可能不同，基金公司不披露当日实际双边申赎量，按黑盒研究；不以取得这些明细作为继续研究的前提。
3. 用户描述的轧差成本分配方式是本版模型的条件假设，不擅自推广到全部基金。
4. 当前按用户最新要求，使用当日最终汇率固定全天，分析完整日内路径与当日净申购关联；不需要盘中汇率预测。每基金每天一条观察，纳入所有有效分钟。
