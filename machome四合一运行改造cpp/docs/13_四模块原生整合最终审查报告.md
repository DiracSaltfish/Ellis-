# 13 四模块原生整合最终审查报告

## 结论

Upload、溢价率监控 A 端、Webull、实时申购赎回已全部进入 `machome-hub-agent`，分别实现 `IModuleEngine` 并运行在四条独立 `QThread`。四合一不再启动四个旧独立程序；只有 Chrome/CDP、Wind ABI、TGW SDK、IBKR TWS API 这类不可信边界使用应用包内、无独立 UI 和无 LaunchAgent 的 helper。

2026-09-04 已按用户授权部署到 machome，只替换 Hub 应用及 Hub 的三份配置。远端默认为工作模式，四个独立程序的部署、LaunchAgent、源码和运行状态未被修改。

## 全局运行模式

| 模式 | 启动与时钟语义 | 写入边界 |
|---|---|---|
| 工作模式 `work` | 默认值。Agent/模块重启必定回到此模式；严格执行旧四程序的工作日、盘中窗口、日终节点、失败重试和自启动作 | 仍受每个模块独立写入闸保护 |
| 周末测试模式 `weekend_test` | 只在当前进程内有效，不持久化。会先为已停止的原生模块设置测试模式，再启动模块；允许在任意时间从 UI 手动连接、采集和运行任务，但不伪造时钟、不自动补跑定时任务 | 不放开生产上传、外部通知、真实 QMT 下单等独立闸保护 |

UI 首页提供中文全局模式选择器，会对四模块发送同一个 `set_operating_mode`。切回工作模式时立即重新评估生产时间边界；测试模式不写入 QSettings 或模块配置。
