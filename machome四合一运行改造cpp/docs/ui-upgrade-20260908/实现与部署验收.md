## 本轮实现

- 总览：卡片保留最小内容高度，放入滚动区域；事件列表可折叠和拖动高度，支持查找、复制、导出。同步卡片使用自己的设备/队列/磁盘指标；模式统计仅等待支持切换的采集模块，同步服务保持常驻。
- 通用列表：增加独立展示代理，支持搜索、数值排序、列显示/顺序/宽度保存、复制、CSV 导出和详情。后台源表保持原顺序，实时行更新和详情回调通过映射对应；带重跑按钮的上传任务使用源表视图，避免丢失按钮或改变任务对应关系。
- 服务概况：收紧指标和说明高度，运行信息单独排列；默认展示六条概况，支持展开全部，移除摘要表内的纵向滚动。诊断刷新保留展开、选择与滚动位置，相同 JSON 不重建。
- Upload：未接入原生明细时直接提供业务网站入口；包内业务模式的净值和留言页面不再显示不可用编辑器。任务表默认精简列，详情保留原始字段；净值表单拒绝无效数字。
- 行情监控：实时信号、全景、历史都有明确详情入口及查找；历史筛选和分页分行。观察列表与额外行情改为结构化列表，支持添加、移除、搜索、批量文本，继续使用原保存协议。
- Webull：盘口改买卖并列；客户端表增加查找、复制、详情和时间汉化；采集模式标明选中项。登录按钮的“开启强制采集”语义保留。
- ETF：监控和提醒分两行，实时表默认展示重点列，提供查看 PCF；观察列表选择可带出名称表单，日期查询改日历。PCF 摘要和成分证券改结构化表格，原文仍可查看；QMT 诊断默认折叠，交易按钮不在服务端页面展示。
- 同步：运行卡片、设备表、最近提交表、分组维护入口及当前操作结果；缺少设备 ack 显示“未报告”，不当作版本 0 或已应用。端口编辑使用服务实际值，维护按钮遵守只读/忙碌状态。
- 日志：查找、复制、导出、跟随最新开关；停止跟随只影响阅读，不停止采集。仍限制为当前控制台接收的最近 500 行。

不扩展交易能力。本轮没有增加 Upload 原生完整网站接口、同步完整历史/版本比较或 Webull 动态换标的协议；这些在方案中被单列为后续能力。原始诊断、日志保留适合的文本视图，没有伪造缺失业务数据。
