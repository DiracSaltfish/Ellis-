# 实时全景空白：字段合同修复（2026-09-07）

## 根因与现场证据

13:45 左右只读连接 machome Agent，收到 197 个就绪标的、上游健康的状态；8 秒内收到 165 条 `premium.summary` 事件。未发出控制、委托或部署命令。

原生 A 核输出的标的字段为 `s`，而 UI 排队和插入表格两处只识别 `symbol/code`，空标的导致整行丢弃。价格实际使用 `last_price_e6`、`iopv_e6`，溢价率使用 `display_premium_ppm`，时间使用 `orig_time`，此前 UI 同样未读取这些字段。普通代理路径可能补入 symbol，原生路径直接发布原始摘要，因此旧的只含 symbol 的 UI 测试漏掉了问题。

## 修复范围

只改 UI：兼容 s 与既有 symbol/code；价格除以 1,000,000，ppm 转百分比除以 10,000；格式化交易所时间；按 source_ready、replay、mapping_verified 显示中文状态。空/非正价格显示占位符，保留旧字段兼容与每 500 毫秒合并刷新机制。没有变更后端协议或任何交易逻辑。
